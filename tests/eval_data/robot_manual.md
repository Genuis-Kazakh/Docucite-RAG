# Robot Manual

## Error codes
Error code E101 means the motor is overheating. Stop the robot and let the motor cool down for 10 minutes.

Error code E205 means the battery is low. Place the robot on the charging dock immediately.

## Charging
The robot battery takes 3 hours to charge fully from empty.

## Safety
The emergency stop button is a big red button located on the top back of the robot. Press it to cut power to all motors.

## Firmware
To update the robot firmware, copy the firmware file to a USB drive, plug it into the service port and restart the robot.
